# 小红书内容生成 Agent 需求文档

版本：v1.0
负责人：待定
适用模型：GPT-5.5 / gpt-image-2
目标平台：小红书
文档类型：产品需求 + Agent 工作流需求 + 生图提示词架构需求

---

## 1. 项目背景

当前需要制作一个对话式 Agent，用户可以通过输入文字需求和上传图片，让 Agent 自动完成小红书内容创作流程，包括：

1. 理解用户需求
2. 分析输入图片
3. 拆解小红书主题
4. 生成标题
5. 生成正文内容
6. 生成小红书标签
7. 生成分层图片提示词
8. 调用 `gpt-image-2` 生图
9. 输出完整小红书发布包

该 Agent 主要服务于内容运营、社群运营、品牌推广、活动招募、产品种草等场景。

---

## 2. 产品目标

### 2.1 核心目标

打造一个可以自动生成“小红书图文笔记”的内容运营 Agent。

用户只需要输入简单需求，例如：

> 帮我发一篇小红书，推广我的 AI 绘画学习社群，目标用户是设计师，希望风格真实一点，可以用我上传的图片做参考。

Agent 需要输出：

- 小红书主题
- 标题候选
- 正文内容
- 标签
- 图片提示词
- 生成图片
- 发布建议

---

## 3. 使用场景

### 3.1 社群招募

用于推广学习社群、训练营、私域社群。

示例：

> 帮我写一篇小红书，招募 AI 绘画社群用户，目标是设计师和内容创作者。

### 3.2 干货分享

用于发布方法论、工具教程、经验总结。

示例：

> 帮我写一篇小红书，主题是普通人如何用 AI 工具提升内容创作效率。

### 3.3 产品种草

用于推广课程、工具、服务、实体产品。

示例：

> 帮我做一篇小红书种草文，介绍一款适合设计师的 AI 出图工具。

### 3.4 活动预告

用于活动报名、直播预热、线下沙龙宣传。

示例：

> 帮我做一篇小红书，预告这周六的 AI 绘画线下分享会。

### 3.5 案例复盘

用于展示成果、用户反馈、社群案例。

示例：

> 帮我根据这张图片写一篇小红书，复盘我们社群成员的 AI 绘画作品成长。

## 4. Agent 总体工作流

```text
用户输入文字需求 / 上传图片
        ↓
需求理解节点
        ↓
图片理解节点
        ↓
信息完整性判断
        ↓
如信息不足，追问用户
        ↓
小红书主题生成
        ↓
标题生成
        ↓
正文生成
        ↓
标签生成
        ↓
封面策略生成
        ↓
分层图片提示词生成
        ↓
图片提示词质量评分
        ↓
如评分不合格，重写提示词
        ↓
调用 gpt-image-2 生图
        ↓
图片质检
        ↓
如图片不合格，重试生图
        ↓
输出完整小红书发布包
```


# 7.8 分层图片提示词生成模块

## 功能说明

生成适合 `gpt-image-2` 的分层图片提示词。

该模块是生图质量的核心，需要使用 12 层提示词架构。

---

## 8. 图片提示词分层架构

图片提示词必须按照以下 12 层生成：

```text
L1 发布目标层
L2 内容主题层
L3 用户人群层
L4 画面主体层
L5 场景环境层
L6 构图版式层
L7 视觉风格层
L8 色彩光影层
L9 情绪氛围层
L10 细节元素层
L11 平台适配层
L12 禁止项与安全边界层
```

---

## 8.1 L1 发布目标层

说明图片用途。

```text
生成一张用于小红书笔记封面的竖版图片，目标是提升点击率、收藏率和用户停留。
```

---

## 8.2 L2 内容主题层

说明图片主题和核心表达。

```text
主题是：AI 绘画学习社群。
核心表达是：设计师不再一个人摸索 AI 绘画，而是在社群中通过案例拆解、提示词练习和作品点评提升出图效率。
```

---

## 8.3 L3 用户人群层

说明图片吸引的人群。

```text
目标用户是：20-35 岁的平面设计师、视觉设计师、小红书内容创作者、AI 绘画新手。
视觉需要干净、有审美、专业但不冰冷。
```

---

## 8.4 L4 画面主体层

明确主体、动作、表情、视觉焦点。

```text
画面主体是一位年轻设计师坐在书桌前使用电脑。
电脑屏幕上展示多张 AI 绘画作品缩略图，内容为抽象插画和产品视觉，不出现文字。
人物表情专注、轻松、有收获感。
核心视觉焦点是电脑屏幕中的创作画面和人物专注工作的状态。
```

---

## 8.5 L5 场景环境层

说明场景地点和背景。

```text
场景是温暖明亮的居家工作室。
背景有灵感板、色卡、简洁插画海报、书架和绿植。
背景干净、有层次，不喧宾夺主。
```

---

## 8.6 L6 构图版式层

控制画幅、主体位置和留白。

```text
竖版构图，比例 3:4。
人物和电脑位于画面中下方。
画面上方保留约 30% 干净留白，用于后期添加标题。
主体清晰，背景简洁，适合小红书信息流展示。
```

---

## 8.7 L7 视觉风格层

控制图片整体风格。

```text
视觉风格为真实生活方式摄影风，带轻微商业摄影质感。
整体干净、明亮、自然，有小红书封面感。
不要过度商业海报化。
```

---

## 8.8 L8 色彩光影层

控制主色调、辅助色和光线。

```text
主色调为奶油白、浅橙色、淡紫色。
辅助色为浅灰和木色。
光线为自然窗光，从左侧柔和照入。
整体低饱和、明亮、温暖但专业。
```

---

## 8.9 L9 情绪氛围层

说明画面情绪。

```text
整体氛围积极、轻松、有成长感和陪伴感。
让用户看到后产生“我也想系统学习 AI 绘画”“这个社群可能有用”的感觉。
不要焦虑，不要压迫，不要鸡血。
```

---

## 8.10 L10 细节元素层

控制辅助元素。

```text
桌面上可以有笔记本电脑、数位板、便签纸、马克笔、咖啡杯、灵感草图。
电脑屏幕中的 AI 绘画作品只作为视觉缩略图展示，不出现可识别文字。
墙面可以有灵感板、色卡和简单图形素材。
细节自然，不要堆砌。
```

---

## 8.11 L11 平台适配层

确保图片适合小红书。

```text
适合小红书封面。
第一眼主体明确，画面有点击感。
上方留白可用于后期添加大标题。
不要在图片中直接生成中文文字。
```

---

## 8.12 L12 禁止项与安全边界层

约束图片不要出现违规或低质内容。

```text
不要生成任何文字。
不要生成 Logo、商标、水印、二维码。
不要出现真实品牌界面。
不要出现真实名人。
不要出现政治、宗教、暴力、低俗元素。
不要出现夸大收益暗示。
不要让人物脸部或手部变形。
不要让背景过度复杂。
```

## 10. 图片提示词质量评分机制

在调用 `gpt-image-2` 前，Agent 需要对图片提示词进行自检评分。

### 10.1 评分维度

```json
{
  "theme_clarity": "主题是否明确，1-5分",
  "subject_clarity": "主体是否明确，1-5分",
  "composition_control": "构图是否可控，1-5分",
  "xiaohongshu_fit": "是否适合小红书，1-5分",
  "style_consistency": "风格是否统一，1-5分",
  "negative_constraints": "禁止项是否完整，1-5分",
  "text_risk": "是否存在生成乱码文字风险，1-5分",
  "overall_score": "综合评分，1-5分"
}
```

### 10.2 重写规则

```text
如果 overall_score < 4，则 Agent 必须自动重写图片提示词。
重写时需要重点加强：
1. 主题明确性
2. 主体清晰度
3. 构图控制
4. 留白区域
5. 小红书平台适配
6. 禁止项完整度
```

## 12. 图片生成后质检机制

生成图片后，需要进行质量检查。

### 12.1 图片质检字段

```json
{
  "is_relevant_to_topic": true,
  "has_text_or_garbled_text": false,
  "has_logo_or_watermark": false,
  "has_qrcode": false,
  "has_sensitive_content": false,
  "has_deformed_face_or_hands": false,
  "is_xiaohongshu_cover_ready": true,
  "has_title_space": true,
  "need_retry": false,
  "retry_reason": ""
}
```

### 12.2 自动重试规则

如果出现以下情况，需要自动重试：

- 图片出现乱码文字
- 图片出现 Logo、水印、二维码
- 图片主题偏离
- 人物脸部或手部明显异常
- 背景过于复杂
- 没有标题留白
- 不适合小红书封面

### 12.3 重试提示词示例

```text
上一张图片出现了无意义文字和复杂背景。
请重新生成一张图片：
保持 AI 绘画学习社群主题，画面更干净，主体更明确。
不要生成任何文字、Logo、水印、二维码。
人物和电脑位于画面中下方，上方保留 30% 干净留白。
```

## 14. Agent 系统 Prompt

```text
你是一个小红书内容策划与社群运营 Agent，擅长根据用户输入的文字需求和图片素材，生成适合小红书发布的完整笔记方案。

你的目标：
1. 理解用户的发布目的、目标人群、产品/活动/社群卖点。
2. 将用户需求拆解为小红书主题、标题、正文、标签、图片提示词。
3. 如果用户提供图片，需要结合图片内容进行分析和再创作。
4. 生成的小红书内容必须真实自然，避免生硬广告腔。
5. 文案要有小红书平台感，包括开头钩子、分段、emoji、痛点、收益、行动引导。
6. 图片提示词必须使用 12 层分层架构。
7. 默认图片不直接生成文字，除非用户明确要求。
8. 不得生成违规、侵权、低俗、虚假承诺内容。
9. 输出内容需要结构化，方便后端调用生图模型。

工作流程：
- 第一步：分析输入需求和图片内容。
- 第二步：判断信息是否完整，如不完整，最多追问 3 个关键问题。
- 第三步：生成 3-5 个主题方向。
- 第四步：选择最适合的主题，生成 3-5 个标题。
- 第五步：生成完整小红书正文。
- 第六步：生成 8-12 个标签。
- 第七步：生成封面策略。
- 第八步：使用 12 层架构生成适合 gpt-image-2 的图片提示词。
- 第九步：对图片提示词进行质量评分。
- 第十步：调用生图工具生成图片。
- 第十一步：检查图片是否符合发布要求。
- 第十二步：输出最终小红书发布包。
```
